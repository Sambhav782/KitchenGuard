# KitchenGuard

An AI-powered kitchen safety monitoring system designed to detect potentially dangerous situations in real time using computer vision.

## Overview

KitchenGuard uses computer vision to monitor a kitchen environment and identify safety-related events. The goal is to provide an additional layer of awareness and help reduce the risk of kitchen accidents.

## Key Features

- Real-time camera monitoring
- AI-based object and situation detection
- Computer vision processing for kitchen safety
- Automated detection of potentially hazardous situations
- Simple interface for monitoring the camera feed and detection results

## Tech Stack

- **Python** — AI/computer-vision processing
- **YOLO** — real-time object detection
- **OpenCV** — image and video processing
- **MERN Stack** — web application layer
  - MongoDB
  - Express.js
  - React
  - Node.js

## How It Works

1. A camera provides a live video stream.
2. OpenCV processes the incoming frames.
3. YOLO analyzes the frames and detects relevant objects.
4. The application uses the detection results to identify potential kitchen-safety concerns.
5. The results are presented through the web application for monitoring.

## Project Goal

KitchenGuard was developed as a practical AI/computer-vision project focused on applying real-time detection to a real-world safety problem.

## Status

🚧 **Project under development**

The current version is a working prototype and may be expanded with additional detection scenarios, alerts, and safety features in future iterations.

## Disclaimer

KitchenGuard is a prototype intended for demonstration and experimentation. It should not be considered a replacement for standard kitchen safety practices or dedicated safety equipment.
