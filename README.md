# KitchenGuard

**AI-powered kitchen safety monitoring using real-time computer vision.**

KitchenGuard is a computer-vision project that uses a camera feed and AI-based object detection to identify potentially dangerous situations in a kitchen environment and provide real-time monitoring.

## Features

- 🎥 Real-time camera monitoring
- 🤖 AI-based object detection using YOLO
- 👁️ Real-time video processing with OpenCV
- ⚠️ Detection of potentially hazardous kitchen situations
- 🌐 Web-based interface for monitoring detection results

## Tech Stack

- **Python** — AI and computer-vision processing
- **YOLO** — real-time object detection
- **OpenCV** — video and image processing
- **MongoDB** — database
- **Express.js** — backend/API layer
- **React** — frontend
- **Node.js** — server-side JavaScript runtime

## How It Works

1. A camera provides a live video stream.
2. OpenCV captures and processes the incoming frames.
3. YOLO analyzes the frames and detects relevant objects.
4. KitchenGuard evaluates the detection results for potential safety concerns.
5. The results are displayed through the web interface for real-time monitoring.

## Project Goal

The goal of KitchenGuard is to explore how **AI and computer vision can be applied to a practical real-world safety problem**. The project focuses on real-time detection and monitoring rather than replacing standard kitchen safety equipment or human supervision.

## Current Status

🚧 **Prototype / Development**

KitchenGuard is currently a working prototype. Additional detection scenarios, alert mechanisms, and safety features can be added in future versions.

## Disclaimer

KitchenGuard is a prototype created for learning, experimentation, and demonstration. It should not be relied upon as a replacement for standard kitchen safety practices, safety equipment, or human supervision.
